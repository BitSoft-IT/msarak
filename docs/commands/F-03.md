# أوامر تنفيذ المهمة F-03 — واجهة رحلة التقييم والحفظ الفوري

## 1. التفرع والتحقق من التحديثات
```bash
git checkout feature/f-03-assessment-ui
git merge main
```

## 2. بناء الأصول البرمجية
```bash
npm run build
```

## 3. تشغيل الفحوصات الآلية
```bash
# تشغيل اختبارات الواجهة المستهدفة
php artisan test tests/Feature/AssessmentUiTest.php

# تشغيل اختبارات الجلسات والإكمال
php artisan test tests/Feature/AssessmentSessionTest.php tests/Feature/AssessmentCompletionTest.php

# تشغيل كامل الفحوصات الآلية للنظام
php artisan test
```

## 4. تنسيق الشيفرة
```bash
./vendor/bin/pint app/Http/Controllers/AssessmentSessionController.php routes/web.php tests/Feature/AssessmentUiTest.php
```

## 5. إنشاء الـ Pull Request
```bash
gh pr create --title "F-03 — تنفيذ واجهة رحلة التقييم والحفظ الفوري وربطها بالخلفية" --body-file ...
```
