# المرحلة الرابعة — حالات استخدام النظام

**الملف:** `SYSTEM_USE_CASES.md`  
**الحالة:** مرشح للاعتماد  
**المرجع:** المتطلبات المعتمدة ومسارات العمل في المرحلة الرابعة.

## 1. الممثلون

| الممثل | الصلاحيات |
|---|---|
| الزائر | التصفح، المقارنة، التسجيل، الدخول، والاستعادة |
| الطالب | التقييم، النتائج، سجل النتائج، وكل وظائف الزائر |
| المدير | إدارة نموذج التقييم وعرض الإحصائيات |
| خدمة البريد | إرسال رابط استعادة كلمة المرور |

## 2. فهرس حالات الاستخدام

## 3. الحالات التفصيلية

### UC-01 — تصفح تخصص

- **الشرط السابق:** لا يوجد.
- **المسار:** فتح الدليل ← اختيار تخصص ← عرض المحتوى والمصادر.
- **البديل:** إظهار القسم الناقص بوصفه غير متاح.
- **النتيجة:** لا تتغير بيانات المستخدم.

### UC-02 — مقارنة تخصصين

- **الشرط السابق:** وجود تخصصين مختلفين.
- **المسار:** اختيار الأول والثاني ← عرض الحقول المشتركة جنبًا إلى جنب.
- **الاستثناء:** يمنع التخصص المكرر أو الاختيار الناقص.
- **النتيجة:** مقارنة للعرض فقط.

### UC-03 — إنشاء حساب

- **الشرط السابق:** الزائر غير مسجل الدخول.
- **المسار:** إدخال البيانات ← التحقق ← إنشاء الحساب.
- **الاستثناء:** بريد مكرر أو بيانات غير صالحة.
- **النتيجة:** حساب جديد دون بريد تفعيل.

### UC-04 — الدخول والخروج

- **الشرط السابق:** حساب موجود.
- **المسار:** إدخال البيانات ← التحقق ← إنشاء جلسة؛ أو طلب الخروج ← إنهاؤها.
- **الاستثناء:** بيانات خاطئة أو حساب بلا صلاحية مطلوبة.
- **النتيجة:** دخول آمن أو إنهاء الجلسة.

### UC-05 — استعادة كلمة المرور

- **الشرط السابق:** الوصول إلى البريد إن كان مسجلًا.
- **المسار:** طلب الرابط ← إرسال رسالة موحدة ← فتح الرابط ← تعيين كلمة جديدة.
- **الاستثناء:** رابط منتهي أو مستخدم أو غير صالح.
- **النتيجة:** كلمة جديدة وإبطال الرابط.

### UC-06 — بدء التقييم أو استئنافه

- **الشرط السابق:** الطالب مسجل الدخول ويوجد نموذج منشور.
- **المسار الأساسي:** لا توجد جلسة نشطة ← إنشاء جلسة مرتبطة بإصدار النموذج.
- **المسار البديل:** توجد جلسة غير مكتملة ← استعادة الإجابات والتقدم.
- **النتيجة:** جلسة غير مكتملة جاهزة للمتابعة.

### UC-07 — تسجيل إجابة

- **الشرط السابق:** جلسة غير مكتملة يملكها الطالب.
- **المسار:** اختيار أقرب وأقل مختلفين أو تعذر الحكم ← تحقق ← حفظ.
- **البديل:** استبدال إجابة سابقة قبل إكمال الجلسة.
- **الاستثناء:** سؤال أو خيار لا ينتمي إلى إصدار الجلسة.
- **النتيجة:** إجابة واحدة حديثة للسؤال.

### UC-08 — إكمال التقييم

- **الشرط السابق:** معالجة 18 موقفًا واحتساب 15 إجابة على الأقل.
- **المسار:** تحقق ← حساب الدرجات ← المطابقة ← حفظ النتيجة ← إكمال الجلسة.
- **الاستثناء:** نقص المواقف أو الإجابات المحتسبة؛ يعود الطالب لإكمالها.
- **النتيجة:** جلسة مكتملة ونتيجة ثابتة مرتبطة بالإصدارات المستخدمة.

### UC-09 — عرض النتيجة

- **الشرط السابق:** نتيجة مكتملة يملكها الطالب.
- **المسار:** عرض أعلى المجالات ← التفسير ← التخصصات المقترحة ← روابط الدليل.
- **البديل:** إظهار المجالات أو التخصصات المتقاربة دون ترتيب مصطنع.
- **النتيجة:** لا تعديل على النتيجة.

### UC-10 — عرض سجل النتائج

- **الشرط السابق:** الطالب مسجل الدخول.
- **المسار:** جلب نتائجه ← ترتيبها زمنيًا ← فتح نتيجة مختارة.
- **الاستثناء:** عند عدم وجود نتائج، تظهر دعوة لبدء التقييم.
- **النتيجة:** عرض النتائج الأصلية دون إعادة حساب.

### UC-11 — إدارة نموذج التقييم

- **الشرط السابق:** المدير مسجل الدخول.
- **المسار:** إنشاء مسودة ← تعديل ← تحقق ← نشر إصدار جديد.
- **الاستثناء:** رفض النشر عند نقص البنية أو اختلال قواعد النموذج.
- **النتيجة:** إصدار منشور للجلسات الجديدة؛ الإصدارات السابقة محفوظة.

### UC-12 — عرض الإحصائيات

- **الشرط السابق:** المدير مسجل الدخول.
- **المسار:** تحديد الفترة ← حساب المؤشرات ← عرضها.
- **الاستثناء:** فترة غير صالحة أو لا تحتوي بيانات.
- **النتيجة:** عرض مجمع دون كشف إجابات طالب محدد.

## 4. قواعد القبول المشتركة

- لا تصل وظيفة محمية دون تسجيل الدخول والصلاحية المناسبة.
- لا يقرأ مستخدم جلسة أو نتيجة لا يملكها.
- لا توجد نتيجة قبل الإكمال والتحقق.
- لا تتغير نتيجة محفوظة عند نشر نموذج جديد.
- لا يعدّل المدير تخصصات الدليل أو نتائج الطلاب.
- كل فشل يحافظ على آخر حالة صحيحة ولا ينشئ بيانات مكررة.
- تعمل المسارات بالعربية وRTL ومن عرض 320px فما فوق.

## 5. قرار المرحلة

تغطي حالات الاستخدام وظائف النسخة الأولى دون تصميم قاعدة البيانات أو API أو الواجهات. تعتمد الوثيقة بعد مراجعة الاتساق مع المتطلبات وتصحيح FR-07 وUS-06 من 15 إلى 18 موقفًا، وتعليق FR-23 في النسخة الأولى.
