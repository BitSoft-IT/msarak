# B-05 — تعريف الإحصائيات الإدارية

تعرض خدمة الإحصائيات بيانات مجمعة فقط، ولا تقرأ محتوى الإجابات ولا تعيد حساب أي نتيجة محفوظة.

| المؤشر | التعريف |
|---|---|
| `started_assessments` | عدد الجلسات التي يقع `started_at` لها داخل الفترة المطلوبة. |
| `completed_assessments` | عدد الجلسات المكتملة التي يقع `completed_at` لها داخل الفترة المطلوبة. |
| `completion_rate` | `completed_assessments / started_assessments × 100`، وتقرب إلى منزلة عشرية. تكون صفرًا عند عدم وجود جلسات بدأت. |
| `top_recommendations` | أكثر خمسة تخصصات ظهورًا داخل التوصيات المحفوظة لنتائج أُنشئت في الفترة، مرتبة حسب العدد تنازليًا ثم المعرف عند التعادل. |

`from` يبدأ عند 00:00:00 في التاريخ المحدد، و`to` ينتهي عند 23:59:59.999999. عند غياب الحدين تستخدم جميع البيانات المتاحة.
